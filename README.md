# meu-cv

Currículo online de Miguel de Oliveira Mello, desenvolvido exclusivamente com HTML, CSS e JavaScript.

## Tecnologias
- HTML5 semântico
- CSS3
- JavaScript

## Funcionalidades
- Layout responsivo
- Menu mobile
- Modo claro/escuro com localStorage
- Animação das seções com IntersectionObserver
- Navegação ativa durante a rolagem
- Ano do rodapé atualizado automaticamente

## Publicação no GitHub Pages
1. Crie um repositório público chamado `meu-cv`.
2. Envie `index.html`, `style.css` e `script.js` para a branch `main`.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.
